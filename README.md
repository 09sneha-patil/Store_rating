# Store_rating
this project allows allows users to register and log in through a single login system. Based on their roles, users can access different functionalities.

Normal users can view registered stores, search for stores, and submit ratings between 1 and 5. Store owners can manage their store information and view ratings received from customers. Administrators can manage users and stores and monitor the overall application.

The main objective of this project is to provide a centralized platform where customers can share feedback about stores through ratings.
